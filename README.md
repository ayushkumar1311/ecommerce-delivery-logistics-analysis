
# E-Commerce Delivery & Logistics Performance Analysis

Team project to analyze e-commerce delivery performance using Python, PostgreSQL, Excel, and Power BI.

## Objectives
- Analyze delivery time and delays
- Measure on-time delivery performance
- Explore order status and customer reviews
- Build an interactive Power BI dashboard

## Dataset
Olist Brazilian E-Commerce Dataset:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
